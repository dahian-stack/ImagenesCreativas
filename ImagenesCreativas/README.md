# Imágenes Creativas S.A.

## Descripción
Aplicación desarrollada en Python y Tkinter para
organizar información relacionada con proyectos audiovisuales.

## Módulos
- Personal creativo y técnico
- Equipos técnicos
- Localizaciones
- Plan de rodaje

## Instalación
1. Instalar Python.
2. Descargar o clonar el repositorio.
3. Ejecutar el archivo main.py.

## Uso
La aplicación contiene cuatro pestañas.
Cada pestaña permite ingresar información mediante
formularios y utilizar los botones Registrar y Limpiar.
