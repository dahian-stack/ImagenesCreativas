# HTML Media — Apuntes en Python

Repositorio de estudio sobre HTML Media basado en W3Schools.
Los ejemplos HTML están guardados como texto dentro de archivos `.py`,
junto con explicaciones de para qué sirve cada etiqueta, qué atributos
son importantes y qué tecnologías antiguas ya no se recomiendan.

## Ejecutar

```bash
python main.py
```

También puedes ejecutar los temas individualmente.

## Temas
- HTML Media
- `<video>`
- `<audio>`
- `<source>`
- `<iframe>` y YouTube
- `<embed>` y `<object>`
- Resumen: qué usar y qué evitar

Fuentes: W3Schools y MDN Web Docs.
